# Mental Health Logger 🧠💙

A Java + MySQL console application that helps students track mood and journal entries.  
Includes basic AI-based sentiment and emotion analysis using Stanford NLP.

## Features
- Add and manage students
- Log daily mood entries
- Write journal entries
- Automatic sentiment detection
- Emotion classification
- View history of moods and journals

## Tech Stack
- Java (Core Java, JDBC)
- MySQL Database
- DAO Design Pattern
- Stanford CoreNLP (Sentiment Analysis)

## How to Run
1. Create database using database.sql file
2. Update DB username/password in DBConnection.java
3. Add Stanford NLP libraries to project
4. Run Main.java
